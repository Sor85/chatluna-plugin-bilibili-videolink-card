# src 说明

适用范围：`src/`。同时遵守根 `AGENTS.md`；客户端见 `client/AGENTS.md`，测试见 `tests/AGENTS.md`。

- 入口仅装配 Config、依赖与生命周期。监听宿主 Koishi 兼容服务的 `attach` 事件：已通过用户/群过滤，不受 AI 是否应答影响，不消费后续消息；只借用宿主适配层，不加载旧版插件。
- 发送通过 `ctx.chat.send`，撤回通过 `ctx.chat.recall`；空 messageIds 是发送失败。使用当前消息的 route，不接受用户参数指定发送目标。
- `media.ts` 为本插件标记的已下载 OneBot 视频注册原生 `chat.encoder`：从 `chatluna_storage` 读取受限字节并保持 data URI，避免宿主默认 5 MiB 阈值把较大媒体变成协议端无法访问的 file://。不接管其他插件媒体、不修改宿主全局媒体配置。
- 链接支持 BV/AV、视频完整链接、b23.tv 与 bili22/23/33/2233.cn 短链、JSON 分享卡片；保留分 P。引用和合并转发内容不递归触发。
- 仅访问 B 站官方 API 与受信 CDN；短链重定向每跳检查 HTTPS 和域名，保留原短链域名，限制跳数。下载逐块检查大小，不能只信 Content-Length；请求同时响应总超时与卸载取消。
- 视频从官方 playurl 获取单段 MP4。不伪造 DASH 无声视频为完整视频，不发送付费或需要权限的内容。附加信息或图片失败可降级，失败原因记录但不记录 Cookie、媒体正文和签名直链。
- 每条消息独立上限，队列串行且有界；缓冲以第一条消息计时，持续输入不无限推迟。去重按平台、机器人、频道、视频与分 P，只在成功处理后记入，过期清理。
- 卡片保留封面、标题、在线人数、标签、五项统计、UP 主、简介、弹幕和热门评论。Takumi 不启动浏览器；用户文本 HTML 转义，远程媒体校验并限额，长文本显式截断。
- 卡片版式以旧版插件为准（`cardHtml`）：封面底部渐变显示时长，在线人数带图标并固定在标题行右侧，统计项只显示填充式图标与数字，评论显示日期、时分秒（Asia/Shanghai）和点赞图标。
- 仅输出图片时不请求视频流。视频时长/大小受限时按配置保留卡片及提示；等待消息无论成功、失败或过滤都在 finally 撤回。

# tests 说明

适用范围：`tests/`。同时遵守根 `AGENTS.md`；实现边界见 `src/AGENTS.md`，验收脚本见 `scripts/AGENTS.md`。

- vitest、tsc 和构建必须在 v2 副本执行，不在独立源码安装依赖。
- 单测覆盖配置、输入/短链安全、官方 API 规范化、分 P、下载限额、超时/卸载、去重/缓冲/过滤、等待提示与发送失败。测试服务通过显式依赖注入，不全局 mock 网络。
- 图片测试实际调用 Takumi 生成 PNG，断言格式及尺寸；端到端通过独立 onebot-sandbox 空间验证真实回复。
- 守卫检查每个分层 AGENTS 已登记且清单路径存在、UI 双语 key 对齐、配置控件契约一致。翻译测试通过与宿主相同的 `@cordisjs/unyaml/vite` 加载实际 YAML，验证扁平键、字符串值及控件使用的标题/说明，不能仅比较源码中的分组名。
- 不提交令牌、下载视频、临时测试页面或运行环境配置。
